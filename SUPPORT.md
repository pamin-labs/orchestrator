# Support

Orchestrator is an early open-source project without a paid support SLA.

- Usage questions and troubleshooting: open a GitHub Discussion when enabled,
  otherwise a focused issue.
- Reproducible bugs: use the bug issue form and include version/SHA, platform,
  Bun/Docker/OpenSandbox versions, exact command, logs with secrets removed, and
  the smallest reproduction.
- Feature ideas: use the idea issue form and describe the owner workflow and
  acceptance evidence, not only an implementation.
- Security or sandbox/credential boundary reports: follow
  [`SECURITY.md`](SECURITY.md) privately.
- Contributions: follow [`CONTRIBUTING.md`](CONTRIBUTING.md).

Search existing issues and the [documentation index](docs/README.md) first. Do
not post tokens, prompts, private repository contents, host paths, or database
copies. Maintainers may convert support requests into documentation or close
questions that cannot be reproduced after requesting the missing evidence.
